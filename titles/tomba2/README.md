`MAIN.EXE` substrate. Its existing code remains in the repository-level `game/` tree; that tree
is Tomba! 2-specific and is not a shared game layer for Tomba! 1. Tomba! 2's optional interpolated
presentation remains title-specific; it is not a policy or dependency for the first game.
